# Knowledge-graph export strategy

Initial exports should represent catalog edges such as:

- resource about exposure or health impact;
- resource scoped to a geographic location;
- resource with environmental context or environmental variable;
- tool computes a variable;
- software implements a covariate calculation;
- project produces or uses a resource; and
- person or organization contributes to a resource or project.

These edges are catalog assertions. Causal or clinical-effect edges require a
separate, explicitly curated assertion model and must not be inferred from
review coding or resource-topic tags.
